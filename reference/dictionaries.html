Dictionaries på én side

En dict gemmer par af nøgle → værdi. Du slår op med nøglen. Kilder: ATBS kap. 7 · Python-tutorial 5.5

Syntaks

d = {"hej": "Hej!", "tak": "Selv tak"}

Opret: {}, par som nøgle: værdi, komma imellem.

d["hej"]

Slå op. Manglende nøgle → KeyError.

d["ny"] = "værdi"

Tilføj (ny nøgle) eller overskriv (eksisterende nøgle). Samme syntaks.

"hej" in d

True, hvis nøglen findes. Tjekker kun nøgler, ikke værdier.

d.get("x", "standard")

Værdien, hvis nøglen findes — ellers standardværdien. Crasher aldrig.

Claudes beskedformat

{"role": "user", "content": "Hello, Claude"}

"role" er "user" eller "assistant"; "content" er teksten. Anthropic: Messages API

Faldgruber

  • Nøgler matcher præcist. "Hej" ≠ "hej".
  • Slå op med nøglen, ikke værdien. besked["user"] → besked["role"]
  • Anførselstegn i f-strenge. f"{besked['content']}" — brug den anden slags inde i {}.
