Reference · opsummering af lektion 1–5

Det har du lært indtil nu

Fem lektioner, ét samlet billede: du kan nu skrive et program, der husker værdier, træffer valg, gentager sig selv og er delt op i funktioner. Det er præcis de fire byggesten, en kommandolinje-chatbot består af. Denne side er til opslag og genlæsning — ingen opgaver. Termerne følger ordlisten.

1 · Arbejdsgangen

python3 hilsen.py

Et script er en tekstfil, der ender på .py. Fortolkeren læser den fra top til bund. Går noget galt, viser Python en traceback — læs den nederste linje først, og kig på linjenummeret. Lektion 1

2 · Variable, typer og f-strenge

navn = "Anna"      # streng
alder = 27         # heltal (int)
alder = 28         # overskriver 27

print(f"{navn} er {alder} år")

En variabel er et navn, der peger på én værdi ad gangen — en ny tildeling glemmer den gamle. f foran anførselstegnet gør, at {navn} erstattes af variablens værdi. ATBS kap. 1

3 · input() og betingelser

alder = int(input("Alder: "))

if alder < 18:
    print("Mindreårig")
elif alder < 65:
    print("Voksen")
else:
    print("Senior")

input() giver altid en streng — brug int() for at regne med svaret. Sammenligninger (== != < > <= >=) giver en boolean. Kun den første sande gren køres. Kolon og 4 mellemrums indrykning markerer blokken. ATBS kap. 2

4 · while-løkker og break

tal = 1
while tal <= 3:
    print(tal)
    tal = tal + 1

Betingelsen tjekkes før hver gentagelse. Glemmer du at ændre tal, får du en uendelig løkke — stop den med Ctrl+C. 

while True:
    x = input("Du: ")
    if x == "afslut":
        break
    print(f"Bot: {x}")
print("Farvel!")

while True: kører for evigt, indtil et break springer ud. Koden efter løkken kører først bagefter. Det er chatbottens skelet. ATBS kap. 3

5 · Akkumulator-mønstret

n = 0              # FØR løkken
sum = 0
while ...:
    n = n + 1      # tæller
    sum = sum + x  # samler op

Samme mønster til at tælle og til at lægge sammen: start-værdi før løkken, og opdatér den samme variabel inde i løkken. Navnet på venstre og højre side af = skal være ens.

6 · Funktioner, parametre og return

def er_myndig(alder):      # alder = parameter
    return alder >= 18

svar = er_myndig(int(input("Alder: ")))
print(svar)                # True/False

def definerer — koden kører først, når funktionen kaldes med (). return sender en værdi tilbage; print() viser den bare. Uden return får du None. ATBS kap. 4

Parameter og argument (formel og aktuel parameter)

def hils(navn):        # navn  = parameter
    return f"Hej {navn}"   #   (formel parameter)

hils("Anna")           # "Anna" = argument
hils(fornavn)          #   (aktuel parameter)

Parameteren er pladsholderen i definitionen — et navn uden værdi, indtil funktionen kaldes. Argumentet er den konkrete værdi, du sender med ved kaldet. Når funktionen kaldes, får parameteren argumentets værdi: navn = "Anna". Argumentet kan være en værdi, en variabel eller et helt udtryk som int(input(...)) — det udregnes først, og så sendes resultatet ind.

Navnene: Pythons dokumentation og fejlbeskeder siger parameter og argument (fx missing 1 required positional argument). Mange danske lærebøger siger i stedet formel parameter og aktuel parameter. Det er de samme to ting. Python-ordlisten: argument · parameter

Scope i én sætning: variable og parametre inde i en funktion findes kun derinde. Skal værdien bruges udenfor, så return den og gem den i en variabel ved kaldet. (Uddybes i en senere lektion.)

Det hele samlet: din echo-bot

def lav_bot_svar(besked):                 # funktion: én opgave, ingen print
    return f"Bot: Du sagde: {besked}"

n = 0                                     # akkumulator
while True:                               # løkke
    x = input("Du: ")                     # input
    if x == "afslut":                     # betingelse
        break
    print(lav_bot_svar(x))                # kald + brug returværdien
    n = n + 1
print(f"Farvel! Du har sendt {n} beskeder.")   # f-streng

Når Claude API'et kommer ind, er det kun indholdet af lav_bot_svar, der skal skiftes ud — løkken forbliver den samme.

Dine egne faldgruber

Fejl du faktisk har ramt og rettet — dem er det værd at kigge efter først, når noget driller.

  • Tildeling vs. sammenligning. if alder = 18: → if alder == 18:
  • Referere vs. kalde. Uden parenteser får du selve funktionen, ikke resultatet. print(lav_bot_svar) → print(lav_bot_svar(x))
  • input() inde i en funktion, der allerede har en parameter. Funktionen skal bruge den værdi, den får — spørg brugeren ved kaldet, ikke indeni.
  • To navne i akkumulatoren. samlet_sum = sum + tal → sum = sum + tal
  • print i stedet for return. Står der None i dit output, mangler en funktion sit return.
  • Streng vs. tal. input() giver "7", ikke 7 — og "7" == 7 er False.

Hvad mangler før Claude-chatbotten?

Claude API'et modtager samtalen som en liste af beskeder, hvor hver besked er en lille ordbog (dict) med en rolle og et indhold. Det er de to nye byggesten, der står for tur — se Anthropics kom-i-gang-guide for, hvordan et kald ser ud.
